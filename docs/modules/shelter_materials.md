# Shelter material decisions (RimWorld 1.6.4871)

An unfinished Wall/Door is considered for a material alternative only when its outstanding ingredients exceed current stock. Loaded catalog costs and compatible stuff govern the choices. Other projects reserve their remaining ingredients. Replacement performs a fresh project identity/catalog/stock check; the existing native projects/cancel endpoint then checks CanPlaceBlueprintAt with the original project ignored and the full unreserved replacement budget before cancellation. A refusal retains the original. Acceptance means a replacement blueprint was observed, not completed construction.

Wood leaf comparisons carry exact current wood, remaining shell need/gap, unroofed sleepers, outside temperature, observed TreeCutting precepts, affordable replacement keys and existing fuel reserve demand. Species criteria describe the actual bounded batch first, then living plant versus dead stump and total population. The same batch helper uses the persisted anchor in candidate and execution. Yield is estimated; native harvest can differ. The Goberium replay stump yield changed from 4 to 3, so it is not guaranteed to close the four-wood gap alone.

TreeConnection is a ritual precept in installed Ideology Precepts_Ritual.xml, not a cutting prohibition. Actual TreeCutting precepts are defined separately in Precepts_TreeCutting.xml. Missing per-pawn cutting mood context remains unknown; choices do not infer a blanket prohibition from Nature primacy or TreeConnection.

A wood defer skips the worker question and persists a signature plus both 30,000 game ticks and a 120-second wall-clock floor. True shell/wood/resource/precept/feasible alternative changes, new severe thermal stage, or clock rollback permit reconsideration. Ordinary job/tick/temperature drift does not reset it. Replacement defer has the same clock floor and suppresses the offered replacement family while wood remains independently available. A refused replacement backs off only that project/material; changed project identity or relevant stock resets it. Laya may still defer every feasible alternative; these changes prevent repeated identical leaves rather than compel harvesting or replacement.

Offline regressions: exact four-wood gap/stump/steel choices; minimal batch; eight-cycle stable defer; stock/gap/ideology/emergency change; clock floor; skip worker; replacement refusal/original preservation; changed identity; per-material failure backoff. No live game mutation was used for this change.

Unknown ingredient counts in partial/legacy projects stay unknown and retain the existing bounded supply option. Generic non-shell demand and cold-room heat construction demand remain available when no shell gap exists. Failed replacement clocks are retained independently per project/material, preventing Steel/Silver retry alternation.
