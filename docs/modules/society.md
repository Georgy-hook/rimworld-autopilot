# People, care and society coverage

Verified against installed RimWorld **1.6.4871 rev590**, Core + Royalty + Ideology + Biotech + Anomaly. Odyssey is not active. Installed XML and Assembly-CSharp are the authoritative implementation evidence; community pages provide supplementary player terminology, not executable eligibility rules.

## Implemented additions

`colony_society.py` owns `society_medical_care`, `society_prisoner_policy`, `society_free_time`. `SocietyController.cs`, `SocietyAutomationHelper.cs`, `SocietyDtos.cs` expose `/api/v1/society/context` and `/api/v1/society/policy`. The collector is read only. Director integration stores its return in `development.society`, calls `prepare`, registers descriptions/domains, and delegates choice/execution/assessment. Installation must include this Python module; the common C# build discovers the new controller.

Every policy uses live exported options, a native Laya person choice, a second Laya policy choice, and **defer at both stages**. Benefit, cost, risk and consequences of leaving the current policy are provided. Python recollects before posting; C# checks current target/map/control/eligibility again. Successful policy changes and explicit Laya deferrals enter the 15,000 tick cooldown; stale refusals do not. These are settings for normal work givers, not completed treatment, recruitment, conversion or learning. No pawn mood, relationship, skill, health or faction is edited directly.

* Medicine ceiling: live hediff severity, immunity, life threatening status, stock, care policy, enabled healthy doctor availability and actual Medicine skill are visible. `NoMeds` means doctor care without medicine; **NoCare is not offered**. Changing a ceiling neither reserves reachable medicine nor assigns an immediate tend job. Existing director urgent tend/rescue/feed actions remain responsible for emergency jobs.
* Prisoner policy: live resistance, current exclusive goal, ideology/certainty, available enabled wardens and Social skill. Recruit, maintain, resistance reduction and conversion are offered only when supported. Resistance reduction requires remaining resistance. Conversion requires active nonclassic Ideology and an available warden of a different ideology. Only adult prisoners are supported by this addition; wild people cannot receive ordinary recruit/resistance orders. Switching goals pauses the old goal; it does not reset resistance/certainty or touch nonexclusive prisoner interactions. Conversion follows the normal acting warden's ideology, not a guaranteed colony target ideology.
* Learning/recreation time: actual NeedDef instances and active child learning desires are exported; children need a Joy or Anything schedule to autonomously learn. A selected **single Work hour** becomes Joy. Sleep/Anything/other hours are preserved. Downed/drafted/mental state/active tend/rescue/feed/surgery pawns are excluded in both Python and C#. This allows activity but does not create a school, teacher, safe outdoor area or materials.

## Decision and execution contract

Every new native opportunity exports five fields: benefit, risk, cost, inaction and uncertainty. Laya first chooses the patient/child, then an available caregiver/doctor when needed, then the actual native giver, bed, recipe or policy entry. Growth separates trait and each passion award. Each stage has defer. Large colonies are narrowed through bounded pairwise comparisons: selected person evidence is retained, and the entire raw society state is not embedded in a token-truncated prompt.

Python re-collects and matches exact native IDs/value before posting `/api/v1/society/order`; C# revalidates the same opportunity and native eligibility. Growth validates actual pending letter, offered indices, exact award count and distinct eligible skills. Existing reversible policies retain `/api/v1/society/policy`. Collector does not open letters, generate growth offers or construct native jobs. Explicit breastfeeding/manual feeding/warden hemogen predicates avoid default HasJobOnThing paths which call JobOnThing; baby safety uses native FindUnsafeBaby and NonScanJob only on execution. Teaching collection calls the native `HasJobOnThing` override: native `JobOnThing` mutates the child's teacher target, so it is called only at execution and restored if dispatch fails.

`PENDING_WINDOWS`, `peek_pending` and `pending_action` allow the director to resolve a growth letter before ordinary work. Deferred choices respect cooldown, including save tick rollback, allowing other colony work while the letter awaits another decision. Terminal game ending is checked by the shared director before these hooks.
